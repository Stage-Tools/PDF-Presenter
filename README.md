PDF Presenter

A browser-based presenter-mode tool for live-event AV professionals. Load a PDF, open the output window on your external display, and run your presentation with slide preview, per-slide notes, and black-screen control — all from a single HTML file, no installation required.


Features


Dual-window presenter mode — presenter view on your laptop, fullscreen output on the external display or video mixer input
Real-time synchronisation — output window updates before the presenter canvas redraws; no perceptible lag
Resizable layout — drag the vertical divider to balance the current-slide area and the right panel; drag the horizontal divider to balance next-slide preview and notes
Per-slide notes — editable live, associated per slide number, saved automatically in folder mode
Layout persistence — divider positions saved and restored per PDF file
Black screen / blank mode — instantly replace the output with a solid black frame without disrupting the presenter view
Folder mode — open an entire event folder; notes and layout positions for all PDFs in the folder are written automatically to a single pdf-presenter-notes.txt file
Drag-and-drop fallback — load a single PDF without folder access; notes stored in memory with manual save option
Keyboard navigation — Arrow keys, Page Up/Down, Space, B for black screen, F11 for fullscreen output
No installation, no server, no internet required — single HTML file; PDF.js is loaded from CDN on first use and cached by the browser



Use Cases


Running PDF-based presentations at live events with a presenter monitor separate from the audience output
Displaying keynotes, rider documents, or show rundowns through a video mixer or media server
Working offline on-site after initial browser cache of PDF.js
